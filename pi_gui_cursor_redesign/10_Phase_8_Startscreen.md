# 10 – Phase 8: Startscreen

## Ziel

Leeren schwarzen Startzustand durch eine funktionale Startoberfläche ersetzen.

## Beispiel

```text
                     Pi

              Was möchtest du tun?

        ┌─────────────────────────────┐
        │ Beschreibe deine Aufgabe... │
        │                    Start →  │
        └─────────────────────────────┘

Letzte Projekte

pi                    vor 12 Minuten
Arbeitsort             gestern
Disa_Ai                27. August
```

Optional:

```text
Letzte Tasks

GUI überarbeiten
Investigator verbessern
Verification Audit
```

## Regeln

- kein Dashboard-Zwang
- keine überladene Statistikansicht
- Taskstart bleibt Primäraktion
- letzte Projekte/Tasks nur sekundär

## Abschlusskriterien

- neuer Task sofort startbar
- keine leere Hauptfläche
- letzte Projekte/Tasks funktionieren
- visuell ruhig
- Keyboard-Fokus sinnvoll
- Build/Test erfolgreich
