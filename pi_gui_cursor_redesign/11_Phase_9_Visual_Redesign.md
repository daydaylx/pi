# 11 – Phase 9: Visuelles Redesign

## Ziel

Erst nach funktionaler Stabilität folgt der visuelle Feinschliff.

## Referenz: Cursor

Übernehmen:

- geringe Border-Dichte
- klare Auswahlzustände
- kompakte Typografie
- sinnvolle Flächennutzung
- subtile Hover-Zustände
- wenige semantische Farben
- sekundäre Panels nur bei Bedarf

Nicht übernehmen:

- Branding
- exakte Farben
- IDE-Look
- VS-Code-Panelstruktur

## Farbsemantik

- Primary → Violett
- Running → neutral/blau
- Success → Grün
- Warning → Orange
- Error → Rot
- Inactive → Grau

## Anforderungen

- Textkontrast ausreichend
- Fokuszustände sichtbar
- keine Farbe als einziges Statussignal
- keine unnötig vielen Karten/Borders
- konsistente Spacing-Skala
- konsistente Typografie
- gute Darstellung bei 1366×768, 1920×1080 und größer

## Abschlusskriterien

- definierte Design Tokens
- konsistente Komponenten
- keine redundanten Akzentfarben
- Statussystem visuell konsistent
- mindestens drei Zielauflösungen getestet
- Screenshotvergleich vorher/nachher erstellt
