# 12 – Phase 10: Agentenintegration

## Ziel

Agenten sichtbar machen, ohne die Oberfläche wieder technisch zu überladen.

## Sidebar/Status

```text
AGENTS

● Pi             Working
● Investigator   Analysing
○ Verifier       Waiting
```

## Activity Stream

```text
Investigator                                     ✓

Repository analysiert
12 Komponenten geprüft
3 Probleme gefunden

▸ Details
```

## Regeln

- Agentenaktivität in Activity Stream integrieren
- Modell/Token/Context pro Agent nur in Details
- keine Multi-Agent-Matrix als Standard
- keine permanente separate Agenten-Konsole
- klare Zuordnung von Activity zu Agent

## Abschlusskriterien

- Agentenaktivität eindeutig zuordenbar
- aktive/wartende/fertige Agenten unterscheidbar
- Details zugänglich
- kein zusätzlicher permanenter UI-Lärm
- Agentenfehler sichtbar
- Build/Test erfolgreich
