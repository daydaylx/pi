Nachvollziehbarkeit. Archivierte Arbeitsaufträge sind keine aktuelle
Umsetzungsanweisung. Für den aktuellen Stand gelten `AGENTS.md`, die aktiven
Dokumente unter `docs/decisions/` und `docs/audits/` sowie offene Aufträge
unter `work/`.
