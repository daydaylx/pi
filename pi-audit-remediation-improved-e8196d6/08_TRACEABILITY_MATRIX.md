# Traceability-Matrix F-01 bis F-28 – Single Source of Truth

Diese Datei ist die **einzige Statusquelle** für alle Audit-IDs. Keine zweite
F-01–F-28-Fortschrittstabelle in anderen Berichten pflegen.

## Statusregeln

- `behoben`: Produktionsänderung + Regressionsevidenz.
- `widerlegt`: konkrete Gegen-Evidenz.
- `bewusst behalten`: dokumentierte Entscheidung mit Rest-Risiko.
- `deferred`: nur P2/P3; Grund + Rest-Risiko + Wiederaufnahme-Trigger.
- `offen`/`blockiert`: nur während Bearbeitung.

Checkpoint A: F-01–F-10 dürfen nicht `offen`, `blockiert` oder `deferred` sein.
Final: keine ID bleibt `offen` oder `blockiert`.
